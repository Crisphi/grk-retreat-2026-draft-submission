# Supplementary Repository for Draft Submission of Chapter Sections | RTG Retreat 2026

This repository contains code, visualisations, corpus metadata, and guidelines for the draft submission of dissertation chapter sections of the PhD project "Building Embodied Publics: A Multimodal Corpus Study of Corporeality and Audience Engagement in Poetry Slam" as part of the retreat by the RTG "Literature and the Public Sphere in Differentiated Contemporary Cultures".

## Structure of this Repository

This Repository consists of the directories `Corpus`, `Scripts`, and `Visualizations`. 

In `Corpus` you can find the [Guidelines for manual data refinement](./Corpus/2026-08-20_guidelines-for-manual-data-refinement-german.pdf), as well as a CSV with the curent status of the [Corpus metadata at time of submission](./Corpus/2026-08-24_corpus-metadata_status-at-submission.csv).

In `Scripts` you can find the [Code used for data crawling and corpus creation](./Scripts/) and the subdirectory `HPE` with scripts for [First exploratory Human Pose Estimations and visualisations](./Scripts/HPE/).

In `Visualizations` you can find the [Visualizations](./Visualizations/) used in the written draft.
